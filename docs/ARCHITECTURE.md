## 阅读一条请求

从浏览器网络请求或接口调用开始，记录 URL、方法和脱敏输入。定位网关路由与过滤器，再找 Controller、Service、Mapper 或客户端调用。记录认证上下文与租户信息如何传递，缓存/事务/权限注解何时生效，最后跟踪响应和异常处理。

每个关键跳转必须附上当前 commit 下的路径与符号名。无法定位时写“待验证”，不要按常见 Spring 项目习惯补全实际行为。

## 阅读一个中间件

区分四层：依赖声明、配置启用、封装入口、真实业务调用。追到真实业务后再观察运行行为。回答：解决什么问题、替代方案是什么、失败如何影响业务、现有实现的边界是什么。
