## 使用规则

源码实现以固定 commit 为准，官方教程需核对适用版本。其他博客和视频只作为辅助线索。记录文章标题、URL、访问日期、适用版本与本地验证结果；无法访问的内容不猜测。

参考聊天“介绍 yudao 框架”（2026-10-11）已读取，用于确定用户学习目标，不作为技术实现证据。该聊天后续可能变化，本项目以进度与源码记录保存持续上下文。
