# 中间件实验清单

以下均为待开始候选。先找到当前版本真实调用点，再选择实验；组件未启用或业务未使用时，记录事实，不强行套用场景。

| 主题 | 最小实验 | 观察证据 | 恢复要求 |
|---|---|---|---|
| 配置与注册 | 修改一个可回滚的学习配置或重启实例 | 配置生效条件、实例注册与发现结果 | 恢复原配置，检查实例健康 |
| 服务调用 | 停止被调用的本地服务后请求调用方 | 超时、异常映射、调用方影响 | 重启服务并重复正常请求 |
| 缓存 | 查询、修改数据、再次查询并等待过期 | 命中、失效路径和一致性窗口 | 恢复学习数据，仅处理实验键 |
| 分布式锁 | 并发触发同一资源操作 | 锁获取、超时、最终数据和重复执行 | 结束任务，确认无遗留锁/数据 |
| 消息 | 使用一种队列方案触发生产与消费 | 消息 ID、消费次数、重试和副作用 | 恢复消费者，检查积压 |
| 定时任务 | 手动触发并制造一次可控失败 | 执行记录、重试与重复触发行为 | 恢复任务设置并检查结果 |
| 限流与超时 | 对学习接口逐步增加请求或注入延迟 | 阈值、错误响应、线程/资源变化 | 停止压力并恢复配置 |
| 链路追踪 | 跟踪正常和失败的跨服务请求 | trace 关联、耗时与失败位置 | 恢复依赖并验证正常链路 |
| 权限与租户 | 使用不同角色/学习租户查询测试数据 | 拒绝结果及隔离边界 | 清理临时账号与测试数据 |

事务一致性等专题放在理解服务边界之后开展，先检查实际事务模型，再决定是否学习分布式事务组件。

## 完成标准

使用实验模板记录源码版本、前置状态、输入、步骤、预期、实际结果、证据和恢复。至少有正常路径与一个失败或边界路径。并发实验需写请求数量、时间窗口、成功失败计数和最终数据，不凭单条日志推断安全性。
